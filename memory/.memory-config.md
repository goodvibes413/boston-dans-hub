# Memory Config — Boston Dan's Hub

This file maps ingestion signal types to their promotion targets in the durable store.

| Signal type | Target | Notes |
|---|---|---|
| Pipeline insight | `decisions/` | Design decisions, architecture changes |
| User feedback | `hypotheses/` | Observation about Dan's voice, quality issues |
| Experiment result | `decisions/` | Agentic pattern test result, model comparison |
| Debugging note | `hypotheses/` | Troubleshooting, failure analysis |
| Session reflection | `hypotheses/` | Lessons from a generation run, what worked |

All signal types default to the durable layer (decisions/, hypotheses/) under the memory
root. The memory pipeline will synthesize from source/ → ingestion/ → durable/.

**Memory root:** `memory/`
**Durable folders:** `memory/decisions/`, `memory/hypotheses/`
**Pipeline folders:** `memory/source/`, `memory/ingestion/`
